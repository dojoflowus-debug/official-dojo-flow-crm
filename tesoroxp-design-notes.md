# TesoroXP Design Analysis

## Header Structure
- **Layout**: Clean minimal header with dark background (#1a1a1a or similar)
- **Logo**: Left-aligned "TESORO" wordmark in white
- **Navigation**: Right-aligned with uppercase text links
  - MERCHANTS
  - GAME STUDIOS  
  - GAMERS
- **CTA Button**: "JOIN THE WAITLIST" in bright orange/yellow gradient
- **Mobile**: Hamburger menu (not visible in desktop view)

## Hero Section
- **Background**: Dark (#1a1a1a) with animated geometric shapes
  - Red/orange hexagonal credit card icon (left)
  - Rainbow gradient octagon (right)
  - Dashed connecting lines between shapes
- **Typography**: 
  - Large white "TESORO" logo
  - Headline: "The rewards platform built for the $125+ Billion gaming economy."
  - Clean sans-serif font (likely Inter or similar)
- **Spacing**: Generous vertical padding, centered content

## Tagline Section
- **Text**: "Your brand. Their game. Everyone wins."
- **Subtext**: "Our patented system connects brands to gamers like never before."
- **Style**: Centered, white text on dark background

## How It Works Section (4-Step Grid)
- **Layout**: 4 columns in horizontal row
- **Steps**:
  1. **Connect** - "Gamers connect their Visa / Mastercard cards to Tesoro."
  2. **Activate** - "Activate offers at participating merchants to earn in-game currency."
  3. **Spend** - "Pay using connected cards in-store, in app, or online."
  4. **Reward** - "Tesoro rewards gamers with in-game currency for each transaction."
- **Typography**: Bold step titles, smaller body text
- **Spacing**: Equal column widths, consistent padding

## Audience Sections (3 Blocks)
Each section follows identical structure:
- **Label**: "for the" in small text
- **Category**: Large uppercase text (MERCHANT / GAME STUDIO / GAMER)
- **Headline**: Not fully visible in extraction
- **Body Text**: Descriptive paragraph
- **CTA**: "Learn more" link
- **Image**: Placeholder or icon on side
- **Spacing**: Generous vertical padding between sections

### Section 1: Merchant
- Text: "Our patented system works seamlessly with any merchant - local, online, or nationwide. Zero integration required."

### Section 2: Game Studio  
- Text: "Leveraging our patent and direct integrations with Visa and Mastercard, Tesoro is building the world's biggest gaming network."

### Section 3: Gamer
- Text: "Tesoro is the only platform where getting in-game currency is effortless and instant."

## Footer Structure
- **Link Columns**: 
  - Merchants
  - Game Studios
  - Gamers
  - About
- **Newsletter**: Email input with "Submit" button
- **Social Icons**: Instagram, LinkedIn, YouTube
- **Legal Links**: CREDITS, TERMS, PRIVACY
- **Layout**: Multi-column grid, dark background

## Design Principles
- **Color Palette**: Dark background (#1a1a1a), white text, orange/yellow accent for CTAs
- **Typography**: Clean sans-serif, uppercase for emphasis, generous line height
- **Spacing**: Lots of whitespace, section-based rhythm
- **Motion**: Subtle animations on geometric shapes
- **Contrast**: High contrast white-on-dark for readability
- **Hierarchy**: Clear visual hierarchy with size and weight


## Additional Observations from Screenshots

### How It Works Cards
- **Background Colors**: Each step has unique bright color
  - Connect: Coral/salmon (#FF6B6B or similar)
  - Activate: Bright yellow/gold (#FFB800)
  - Spend: Bright green (#00D084)
  - Reward: Cyan/turquoise (#00C9DB)
- **Card Style**: Rounded corners, generous padding, icon at top
- **Layout**: 4-column grid on light mint green background (#D4F4DD)
- **Icons**: Simple black illustrations for each step
- **Typography**: Bold black titles, smaller gray body text

### Audience Section Styling
- **Label "FOR THE"**: Small uppercase text in center
- **Category Badge**: "MERCHANT" in bordered box/badge
- **Background**: Light mint green continues from How It Works
- **Headline**: Large bold text in dark green/black
- **Layout**: Centered text with image/photo on side

### Color Transitions
- Dark hero section → Light mint green for content sections
- Creates clear visual separation between sections
- High contrast for readability

### Typography Scale
- Hero: Very large (60-80px)
- Section headlines: Large (40-50px)
- Step titles: Medium (24-30px)
- Body text: Standard (16-18px)
- All using consistent sans-serif family

## Key Takeaways for DojoFlow Implementation

1. **Maintain dark theme** throughout (already established in hero)
2. **Use geometric shapes** sparingly for visual interest (already have Kai cards)
3. **Clean typography hierarchy**: Large headlines, readable body text
4. **Generous spacing** between sections (breathing room)
5. **High contrast** for accessibility (white on dark)
6. **Consistent color accents** for CTAs (use DojoFlow red/orange)
7. **Simple navigation structure** (3 main audience links)
8. **Newsletter in footer** (email capture)
9. **Social proof** through social icons
10. **Mobile-responsive** hamburger menu
