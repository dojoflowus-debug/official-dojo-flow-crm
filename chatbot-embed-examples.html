🥋 DojoFlow Chatbot Embed Examples

Copy and paste these code snippets to embed the chatbot on your website

1. Full Page Embed

Perfect for a dedicated chat page or landing page.

<!DOCTYPE html> <html> <head> <title>Chat with Kai</title> <style> body, html { margin: 0; padding: 0; height: 100%; overflow: hidden; } iframe { width: 100%; height: 100vh; border: none; } </style> </head> <body> <iframe src="https://dojoflow-2awpr243.manus.space/lead-capture?org=120001" allow="microphone" title="DojoFlow Chat"> </iframe> </body> </html>

2. Inline Section Embed

Embed the chatbot as a section within your existing page.

<div style="max-width: 800px; margin: 40px auto;"> <h2>Chat with Our Virtual Assistant</h2> <iframe src="https://dojoflow-2awpr243.manus.space/lead-capture?org=120001" style="width: 100%; height: 600px; border: none; border-radius: 12px; box-shadow: 0 4px 16px rgba(0,0,0,0.1);" allow="microphone" title="DojoFlow Chat"> </iframe> </div>

3. Floating Chat Widget (Bottom Right)

Add a floating chat button that opens the chatbot overlay.

<!-- Add before closing </body> tag --> <style> #kai-chat-widget { position: fixed; bottom: 20px; right: 20px; width: 400px; height: 600px; border: none; border-radius: 16px; box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3); z-index: 9999; display: none; } #kai-chat-widget.open { display: block; } #kai-chat-button { position: fixed; bottom: 20px; right: 20px; width: 60px; height: 60px; border-radius: 50%; background: linear-gradient(135deg, #3b82f6 0%, #2563eb 100%); border: none; cursor: pointer; box-shadow: 0 4px 16px rgba(59, 130, 246, 0.4); z-index: 9998; } #kai-chat-button.hidden { display: none; } </style> <button id="kai-chat-button" onclick="toggleKaiChat()">💬</button> <iframe id="kai-chat-widget" src="https://dojoflow-2awpr243.manus.space/lead-capture?org=120001" allow="microphone"></iframe> <script> function toggleKaiChat() { const widget = document.getElementById('kai-chat-widget'); const button = document.getElementById('kai-chat-button'); widget.classList.toggle('open'); button.classList.toggle('hidden'); } </script>

5. WordPress Shortcode

Add this to your theme's functions.php file, then use the shortcode in any page.

// Add to functions.php function dojoflow_chatbot_shortcode($atts) { $atts = shortcode_atts(array( 'org' => '120001', 'height' => '600px' ), $atts); return '<iframe src="https://dojoflow-2awpr243.manus.space/lead-capture?org=' . esc_attr($atts['org']) . '" style="width: 100%; height: ' . esc_attr($atts['height']) . '; border: none; border-radius: 8px;" allow="microphone" title="DojoFlow Chat"> </iframe>'; } add_shortcode('dojoflow_chat', 'dojoflow_chatbot_shortcode'); // Usage in WordPress editor: [dojoflow_chat org="120001" height="700px"]
